# RQ3-2A Clean Project

This directory is a cleaned project snapshot for **RQ3-2A**. Its purpose is to regenerate the result files that map directly to the paper tables and figures.

The project is split into:

- `core/`: core computation logic for evaluation and plot-ready outputs
- `script/`: table-building, validation, and SBERT smoke-test scripts
- `input/`: required inputs
- `output/`: detailed outputs from the main pipeline
- `table/`: paper-facing CSV / TeX / PNG artifacts
