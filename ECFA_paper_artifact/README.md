# ECFA Paper Artifact

> Research artifact for **From Clusters to Views: Entity-Centric Functional Aggregation of Crowdsourced Test Reports**.

## 1. Overview

This package is organized as a paper-facing artifact for the ECFA study. It contains the source code, representative inputs, and supporting notes needed to inspect the three experimental tracks covered in the paper:

- **RQ1**: structural effects of entity unification on the evidence graph
- **RQ2**: budget-aware selection, ablations, and baseline comparison
- **RQ3**: cross-cluster recovery, protocol comparison, and human audit
